# E-Commerce Microservices

E-Commerce application built using Spring Boot and Spring Cloud.

## Services

|     Service       |             Description                   |
|---------------------------------------------------------------|
| User Service      | User registration, authentication and JWT |
| Product Service   | Product management                        |
| Inventory Service | Inventory management                      |
| Order Service     | Order management                          |

## Technology

- Java 21
- Spring Boot 3.5.7
- Spring Cloud 2025.0.x
- Spring Data JPA
- MySQL
- Spring Security
- JWT
- Maven
